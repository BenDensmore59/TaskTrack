# TaskTrack

Program that allows for task adding and viewing for daily task management.

## Current Features

-[Task adding]
-[Task viewing]
-[Persistent storage]

## Requirements

-Python 3

## Project Files

-`tasktrack.py` — Main file that holds all the features
-`tasks.txt` — Where the tasks are stored
-`.gitignore` — Files that are to be ignored by git

## Running the Program

[A terminal can be opened from the upper left "Terminal" tab]

```text
[python tasktrack.py]
```

## Task Persistence

[Tasks are loaded from and saved to tasks.txt]

## Sample Interaction

```text
[After execution, the program prompts the user for an input corresponding to the user's desired choice. You can view the tasks, add tasks to be viewed, and exit the program.]
```

## Current Limitations

-[Task editting]

## Version Control

[The project uses git and github to upload to a cloud repository from a local repository. Changes can be committed, and then pushed to the cloud repository on github. To update the project locally pull the latest updated version from github]
